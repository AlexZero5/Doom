# Ассеты FunDoom

Здесь лежит вся графика и карты. Игра при запуске сама находит эту папку, декодирует
картинки в бинарный кэш `.cache/` (быстрее PNG-парсинга) и **на лету подхватывает
изменения**: перекрасил файл в редакторе — сохрани — картинка в игре обновилась сама.

Почти всё здесь сгенерировано кодом в `tools/AssetForge` (см. README в корне). Править
можно и руками, но следующий запуск AssetForge перезапишет файл — надёжнее поправить код
картинки в `tools/AssetForge/Art/`.

## Структура

```
assets/
  textures/     материалы 64×64 по именам + textures.txt (метров на один повтор картинки)
                имя файла = имя текстуры в карте
  sky/          панорамы неба 512×128 (day, dusk): от зенита (верх) до горизонта (низ)
  weapons/      оружие: weapons/<ствол>/<кадр>.png — idle, fire1…, punch1…, pump1…
                (кадр 400×240 — нижняя середина экрана 640×400)
  anims/        снаряды и взрывы: папка = клип, кадры 0.png, 1.png… + manifest.json
  sprites/      бонусы (pickup_*) и декорации (decor_*) + sprites.txt —
                сколько пикселей картинки приходится на метр мира
  hud/          statusbar.png (320×32), big_*/small_* — цифры, face_* — лица
  ui/           font.png + font.txt (атлас шрифта), fill_* — заливки букв,
                logo, panel (рамка 9 частями), skull_0/1, slider_*, check_*
  maps/         карты: town.map — «Городок у замка» (собирает tools/MapForge)
  .cache/       бинарный кэш — НЕ редактировать, можно удалять целиком
```

## Правила

- Формат: PNG, 8 бит, без interlacing. Поддерживаются RGBA, RGB, палитра (+tRNS),
  градации серого. Прозрачность — по альфа-каналу (лучше бинарная: 0 или 255).
- Шрифт `ui/font.png` хранит не цвет, а «объём» буквы в оттенках серого: цвет даёт заливка
  `ui/fill_*.png`. Поэтому одна буква рисуется в любом состоянии (обычная, при наведении,
  заголовок, значение) — новая заливка = новый цвет текста без перерисовки шрифта.
- Нет картинки? Не беда: стены рисуются процедурным кирпичом, меню — встроенным шрифтом,
  строка состояния — текстом.
- Анимация: рядом с кадрами положи `manifest.json`:

  ```json
  { "frameTime": 0.08, "loop": false }
  ```

  `frameTime` — длительность кадра в секундах (по умолчанию 0.12), `loop` — зацикливать
  ли (по умолчанию true).
- Кэш инвалидится автоматически по времени изменения PNG. Если сомневаешься —
  удали папку `.cache`, игра пересоберёт её.

## Генерация картинок нейросетью прямо из консоли (tools/ImgGen)

```
"C:\Users\alex1\.dotnet\dotnet.exe" run --project tools\ImgGen -- ^
  --out assets\textures\my_wall.png --quality high --prompt-file prompt.txt
```

- По умолчанию модель `openai/gpt-image-1` (настоящий PNG, прозрачный фон, ~0₽).
  `--model google/gemini-3.1-flash-image` — дешевле, но возвращает **JPEG** (в assets
  нельзя, инструмент предупредит и вернёт код 3).
- `--ref картинка.png` — референс для img2img (тик выстрела из idle-спрайта).
- `--background transparent` — прозрачный фон для оружия/вспышек.
- `--size ШxВ` / `--aspect 1:1 --res 1K|2K|4K` — размер.
- Ключ берётся из env `ROUTERAI_API_KEY` или `~/.qwen/settings.json`.

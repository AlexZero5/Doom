# Ассеты FunDoom

Сюда складываются PNG-текстуры. Игра при запуске сама находит эту папку, декодирует
картинки в бинарный кэш `.cache/` (быстрее PNG-парсинга) и **на лету подхватывает
изменения**: перекрасил файл в редакторе — сохрани — картинка в игре обновилась сама.

## Структура

```
assets/
  walls/        текстуры стен: <тип клетки>.png — walls/1.png … walls/5.png
  weapons/      оружие от первого лица: fist.png, chainsaw.png, pistol.png,
                shotgun.png, chaingun.png, rocketlauncher.png, plasmarifle.png, bfg9000.png
  sprites/      спрайты предметов (задел на будущее)
  anims/        анимации: папка = клип, кадры называются 0.png, 1.png, 2.png…
    muzzle/     вспышка у дула (loop: false — замирает на последнем кадре)
  .cache/       бинарный кэш — НЕ редактировать, можно удалять целиком
```

## Генерация картинок нейросетью прямо из консоли (tools/ImgGen)

```
"C:\Users\alex1\.dotnet\dotnet.exe" run --project tools\ImgGen -- ^
  --out assets\walls\1.png --quality high --prompt-file prompt.txt
```

- По умолчанию модель `openai/gpt-image-1` (настоящий PNG, прозрачный фон, ~0₽).
  `--model google/gemini-3.1-flash-image` — дешевле, но возвращает **JPEG** (в assets
  нельзя, инструмент предупредит и вернёт код 3).
- `--ref картинка.png` — референс для img2img (тик выстрела из idle-спрайта).
- `--background transparent` — прозрачный фон для оружия/вспышек.
- `--size ШxВ` / `--aspect 1:1 --res 1K|2K|4K` — размер.
- Ключ берётся из env `ROUTERAI_API_KEY` или `~/.qwen/settings.json`.

## Правила

- Формат: PNG, 8 бит, без interlacing. Поддерживаются RGBA, RGB, палитра (+tRNS),
  градации серого. Прозрачность — по альфа-каналу.
- Нет текстуры? Не беда: стены рисуются процедурным «кирпичом», оружие — встроенной
  графикой. Удалите PNG — вернётся процедурный вид.
- Стены: если в текстуре есть прозрачные пиксели, сквозь них виден базовый цвет клетки.
- Анимация: рядом с кадрами положи `manifest.json`:

  ```json
  { "frameTime": 0.08, "loop": false }
  ```

  `frameTime` — длительность кадра в секундах (по умолчанию 0.12), `loop` — зацикливать
  ли (по умолчанию true).
- Кэш инвалидится автоматически по времени изменения PNG. Если сомневаешься —
  удали папку `.cache`, игра пересоберёт её.

# Итерация 2: скорость, стиль, оружие, HUD, новая карта

Рабочий файл итерации: ТЗ → анализ → план → решения → проверка. Обновляется по ходу работы.

## 1. ТЗ (своими словами)

1. **Ещё быстрее на максимальных настройках.** Изучить современные техники; рисовать только
   видимое; «размытие в движении» — в движении кадр чуть хуже, зато быстрее.
2. **Нормальное тематическое меню**: свой растровый шрифт картинками (русский + английский),
   заливка отдельно — обычная и hover.
3. **Новые текстуры** стен, полов, неба — красивее, правильнее, с запасом под будущие локации.
4. **Оружие и анимации**: нормальные стволы (пулемёт сейчас «смотрит вверх»), у каждого своя
   анимация выстрела (у пулемёта вращается барабан, кулак бьёт, пила пилит), анимированные
   снаряды без «зелёной обводки», без общего «качания» при выстреле — покачивание только
   при ходьбе.
5. **Графический HUD** из PNG, цифры своим шрифтом, анимированное лицо героя как в Doom.
6. **Новая карта**: одноэтажный дом с двором, задействовать все возможности движка.
7. Общий единый стиль: «человечнее, немного грубее», а не «нейронно». Инструмент ImgGen
   прошлого агента не трогать — генерировать своими методами.

## 2. Анализ

- Нейросетью картинки я генерировать не могу, поэтому пишу **свой генератор пиксель-арта**
  `tools/AssetForge`: всё рисуется кодом — фигуры, шум, дизеринг, ограниченные палитры,
  обводка. Это и даёт единый «рукотворный» стиль: низкое разрешение (текстуры 64×64),
  2–3 оттенка на материал, чёткие пиксели, без размытых градиентов. Результат
  детерминирован (фиксированные seed) — можно перегенерировать и править код.
- Исследование (поиск): стандартный приём — **динамическое разрешение** по таймингу
  (Unity/Unreal Dynamic Resolution): в нагрузке рендерить меньше уникальных пикселей.
  Для терминала это особенно выгодно: одинаковые соседние ячейки почти бесплатны по байтам
  (цвет терминала уже стоит). Синхронизированный вывод (DECSET 2026) Windows Terminal
  поддерживает с 1.24/1.25 — уже используем.
- «Рисовать только видимое» уже так: рейкастинг трассирует только видимые колонки,
  3D-объекты отсекаются по углу обзора и спиной, пол/потолок не считаются под стенами.
  Главный резерв — **меньше уникальных цветов на кадр**:
  1. освещение ступенями (как COLORMAP в Doom, 32 уровня) — соседние пиксели одной
     поверхности получают одинаковый цвет;
  2. пиксель-арт текстуры с плоскими участками вместо шумных нейро-текстур;
  3. «размытие в движении» — в движении усредняем соседние колонки (и половинки ячеек),
     в покое — полное качество.
- Движок нужно расширить под дом: текстуры по именам (а не номера 1..9), стены разной
  высоты, «обои» комнаты на внутренней стороне стен, верх низких стен (подоконники, забор),
  глубина потолка (крыша над домом не должна просвечивать в комнату), декорации-спрайты,
  мебель из 3D-боксов с текстурой на каждую грань, повторяющиеся UV.
- Карта — **файлом** (`assets/maps/*.map`), а не кодом: задел под будущие локации.

## 4. Решения

**Графика — кодом, своим инструментом (`tools/AssetForge`).** ImgGen прошлого агента не
тронут. Единый стиль даёт общая палитра 256 цветов (16 рамп × 16 оттенков) с упорядоченным
дизерингом и бинарной прозрачностью: у спрайтов нет полупрозрачной «каймы» — именно она
давала зелёную обводку у снарядов.

**Оружие — 3D, а не рисунок.** Плоские 2D-фигуры выглядели «пластиково». Стволы собраны из
SDF-фигур (цилиндры, фаски, торы, гладкие объединения) и отрендерены трассировщиком: металл
с отражением неба и пола, затенение впадин, блики, контурные линии по разрывам глубины.
По отзывам переделано трижды:
- руки → бронеперчатки с пластинами и болтами, руки не проходят сквозь ствол;
- пила — диагональная шина, одна рука; ракетница — труба на плече без рук;
- пистолет — тяжёлый пистолет (не бластер, по просьбе);
- пулемёт — полный корпус с мотором и патронным коробом, блок стволов вращается;
- плазмаган и BFG — металлические корпуса с камерой/реактором, рёбрами, катушками.

Анимации — свои у каждого ствола (`WeaponAnimations`): кулак бьёт поочерёдно (зеркалом),
пила тарахтит на холостых, у дробовика цевьё, у пулемёта кадр по номеру выстрела, у BFG —
разгон. Общий «кивок» при выстреле убран; покачивание — только при ходьбе.

**Карта — файлом.** `assets/maps/house.map`: легенды текстур, сетки стен/полов/потолков и
список предметов. Новые возможности движка ради дома:
- стены разной высоты, верх низких стен виден (подоконники, забор);
- «обои» комнаты: грань стены берёт текстуру комнаты, из которой на неё смотрят;
- глубина потолка — крыша не просвечивает в комнату;
- мебель и крыши — 3D-боксы с текстурой на каждую грань и UV по размеру;
- декорации-спрайты (деревья, лампы, бочки), твёрдые для игрока.

**Оптимизация.** Узкое место — байты в терминал, а их число растёт с числом смен цвета.
- Свет ступенчатый (32 уровня).
- Мип-уровни текстур на расстоянии: меньше «шума» соседних ячеек.
- Упрощение кадра в движении. Сначала это была отдельная настройка «Размытие в движении»
  (выкл/мягкое/сильное). По замечанию оно стало оптимизацией, которая работает **всегда**:
  в движении колонки усредняются попарно и цвет огрубляется до 5 бит на канал. Галка
  «Грубее в движении» включает блоки 2×2 и 4 бита. Стоит остановиться — сразу полный кадр.
  Классическое «размытие следа» не делалось: это эффект графики, он добавил бы работы.

**Меню.** Растровый шрифт хранит «объём» буквы в сером, цвет даёт отдельная заливка —
поэтому обычная, hover, заголовок и значения — это одна и та же буква с разными заливками.
Панель — картинка «9 частями», череп-указатель мигает, ползунки и галочки — картинки.
Масштаб подбирается под окно; если не влезает — прячется логотип и включается прокрутка.

**HUD.** Панель 320×32 масштабируется под ширину окна, вид над ней укорачивается
(`HudRenderer.RowsFor`). Лицо: смотрит по сторонам, ухмыляется при находке оружия, злится при
долгой стрельбе.

## 5. Проверка

Стенд (скрипт вне репозитория) рендерит кадры игры в PNG без запуска самой игры (она
разворачивает окно и жмёт Ctrl+−), гоняет вывод через эмулятор терминала и меряет байты.
Самотест `.qwen/tmp/rendertest` переписан под новую карту.

- Сборка Debug и Release: 0 ошибок, 0 предупреждений.
- Самотест: 17/17 OK — карта грузится, все текстуры есть, бонусы в проходимых клетках,
  с крыльца виден дом и крыша, игрок упирается в диван и забор, ракета взрывается о дом,
  упрощение в движении уменьшает число разных ячеек (2082 → 1218 → 241), рендер 1.3 мс.
- Эмулятор терминала: пакеты презентера восстанавливают кадр **без единой ошибки** в обоих
  режимах вывода (дифф и полный кадр), в том числе вперемешку с упрощёнными кадрами и меню.
- Замер на кадре 400×110 (КиБ на кадр):

  | Режим | Поворот | Ходьба |
  | --- | --- | --- |
  | Полное качество | 386 | 270 |
  | В движении | 287 (−26%) | 207 (−23%) |
  | В движении, «Грубее» | 152 (−61%) | 99 (−63%) |

- Осмотр кадров: двор, фасад с крышей, гостиная, спальня, ванная, коридор, кухня,
  кабинет, вид из окна, задний двор, сарай, пруд; анимации всех 8 стволов; меню (главное,
  настройки, читы) в маленьком и большом окне.
- Найдено и исправлено при осмотре:
  - крыша сливалась с кирпичом и дымкой неба → черепица тёмно-коричневая, скат круче;
  - меню вылезало за экран в маленьком окне → масштаб по высоте над подсказкой, логотип
    прячется;
  - подсказка обрезалась → в узком окне выпадают первые части, «Esc …» остаётся;
  - у машины не было текстур `car_red` / `glass_dark` → добавлены.

Что не проверялось автоматически: сама игра в живом Windows Terminal (стенд не запускает
её из-за автозума окна) — это стоит прогнать руками.
